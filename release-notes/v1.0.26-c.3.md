## 주요 변경

- **씬+**: 씬마다 캐릭터 슬롯을 구성하고, 캐릭터 별 프롬프트 추가 및 위치 지정을 할 수 있습니다. 출연 또는 출연 그룹을 배정해 여러 조합을 예약 생성할 수 있습니다.

## 다운로드

- Windows x64: `nais3-1.0.26-c.3-setup.exe`
- Mac Apple Silicon: `nais3-1.0.26-c.3-arm64.dmg`
- Mac Intel: `nais3-1.0.26-c.3-x64.dmg`

Mac ZIP과 Windows 업데이트 메타데이터는 앱 내 자동 업데이트에 사용됩니다.
